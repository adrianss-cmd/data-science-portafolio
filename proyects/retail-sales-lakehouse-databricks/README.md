# Retail Sales Lakehouse Pipeline using Databricks

## Overview

This project demonstrates the design and implementation of an end-to-end Lakehouse architecture using Databricks and Apache Spark.

The pipeline follows the Medallion Architecture (Bronze, Silver, Gold) to transform raw e-commerce data into trusted analytical datasets for business intelligence.

The project is based on the Olist Brazilian E-Commerce Dataset and simulates a real-world data engineering workflow.

## Technologies

- Apache Spark (PySpark)
- Delta Lake
- SQL
